Sincronização Compartilhada

Como o app é hospedado de forma estática no GitHub Pages, ele utiliza uma base em nuvem gratuita para que todos os membros do grupo vejam e atualizem as mesmas entregas em tempo real.

Configuração Gratuita com Firebase Realtime Database

  1. Acesse o Firebase Console e crie um projeto gratuito.
  2. No menu lateral, vá em Build → Realtime Database e clique em Criar Banco de Dados.
  3. Inicie em modo de teste (leitura e escrita públicas).
  4. Copie a URL gerada (terminada em .firebaseio.com) e cole abaixo:
Exemplo: https://nome-do-grupo-default-rtdb.firebaseio.com

Após salvar a URL, envie este link para a equipe no WhatsApp/Teams. Quem abrir já entra sincronizado automaticamente:

Configure a URL acima para gerar o link da equipe.
